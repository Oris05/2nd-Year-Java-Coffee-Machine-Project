Simple Coffee Machine (Java)
A small Java console program that simulates a basic coffee machine.
Made as part of a 2nd‑year OOP module assignment.

What it does?
Lets the user pick a drink (Espresso, Americano, Latte), checks if the users input is correct, 
then plays the correct wav file according to the choice, waits until the file is finished playing,
and continues the program. Runs fully in the console

Why I built it?
To practice: Java classes, objects, threads Encapsulation, state management and simple project structure.

How to run?
Open the project in any Java‑supported IDE and run Coffee_Machine.java.
